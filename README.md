# 루루냥의 제주농사

제주 들판에서 귤을 따 상자에 담고, 택배사에서 육지로 부치는 3D 게임입니다.
브라우저만 있으면 되고, 따로 설치할 것은 없습니다.

## 조작

**컴퓨터**

| 키 | 하는 일 |
|---|---|
| 방향키 | 루루 이동 |
| A D | 시야 좌우로 돌리기 |
| W S | 올려보기 / 내려다보기 |
| Z X | 줌 |
| F | 귤 따기 · 상점 · 택배 |
| E | 상자 잡기 / 놓기 |
| Shift | 달리기 |
| Space | 점프 |
| M | 배경음악 켜기 / 끄기 |

**폰**

- 왼쪽 화면을 끌면 루루가 걸어갑니다 (살짝 기울이면 천천히)
- 오른쪽 화면을 끌면 시야가 돌아갑니다
- 두 손가락으로 벌리고 오므리면 줌
- 오른쪽 아래 버튼: 🍊 따기·거래 / 📦 상자 / 💨 달리기 / ⤴ 점프

## 놀이 방법

1. 감귤나무 가까이서 **F**를 눌러 귤을 땁니다. 딴 귤은 상자에 한 알씩 쌓입니다 (36알이면 가득).
2. 상자 옆에서 **E**를 눌러 붙잡고, 마당 왼쪽 **택배사**까지 끌고 갑니다.
3. 택배사 앞에서 **F** — 귤이 트럭에 실려 육지로 가고 정산을 받습니다 (한 상자 14,400원).
4. 10만원을 모으면 옆 **상점**에서 끈을 살 수 있습니다. 끈이 있으면 상자가 알아서 따라옵니다.
