# 루루냥의 제주살이

> 루루는 제주에서 태어난 고양이가 아니다. 원래는 서울에서 살았다.
>
> 스무 살의 루루가 눈여겨본 서울의 작은 아파트는 5억이었다.
> "10년만 열심히 모으면, 대출 끼고 살 수 있을 거야."
>
> 10년을 쉬지 않고 일하고, 아끼고, 모았다.
> 서른 살이 된 루루의 전 재산은 — 4,000만 원.
> 그사이 그 아파트는 20억이 되어 있었다.
> 집값은 월급보다, 저축보다, 꿈보다 훨씬 빨랐다.
>
> 루루는 꿈을 접었다. 그리고 마지막 희망을 품고 —
> 전 재산을 털어, 제주 외딴 마을의 빈집 하나를 샀다.
>
> 집은 비가 새고, 전기는 끊겼고, 잡초는 허리까지 자라 있었다.
> 하지만 루루는 웃었다.
>
> **"적어도… 여긴 내 집이다."**
>
> 서른 살, 루루의 두 번째 인생이 시작된다.
> 언젠가 이 낡은 집을 제주 최고의 집으로 만드는 것 —
> 그것이 루루의 새로운 꿈이다. 🍊

고양이 루루가 제주에서 귤 농사, 해녀 물질, 조랑말 키우기, 집 꾸미기를 하며
두 번째 인생을 사는 3D 게임입니다. 브라우저만 있으면 되고, 설치할 것은 없습니다.

## 할 수 있는 일

### 🍊 감귤 농사
- 귤 상자를 곁에 끌고 다니며 나무 앞에서 **F(🐾)** 로 귤을 땁니다
- 상자를 **가득 채워** 택배사에 가져가면 이장님이 **한 박스 10,000원**에 사 줍니다
- 황금향이 열리는 날엔 열 알에 하나꼴로 황금향(3배 값)이 섞여 있습니다

### 🤿 해녀 물질
- 상점에서 **망사리**(10,000원)를 사서 등에 메고, 포구 **축대 끝**까지 걸어가면 입수
- 물속에서는 화면에 보이는 그대로 움직입니다 — **↑ 떠오르기 · ↓ 잠수 · ← → 좌우 헤엄**
- 채집물: 미역 1,000 / 소라 10,000 / 전복 20,000 / **문어 50,000원** (딱 두 마리!)
- 숨은 60초, **산소통**(100,000원)을 사면 3분
- **숨이 다하면 정신을 잃고, 가진 돈을 전부 잃습니다.** 포구의 해녀 할망이 늘 하시는 말 —
  *"욕심내민, 바당이 데려간다."*

### 🏚 내 집 고치고 꾸미기
- 남쪽 언덕의 낡은 돌집이 루루의 집입니다. 문 앞에 서면 안으로 들어갑니다
- 상점 공구(망치·톱·페인트)로 벽·지붕·칠을 직접 고칩니다
- 상점 안에서 **가구**(침대·의자·식탁·옷장)와 **바닥재·벽지**(색상 선택)를 사서 꾸밉니다
- 집을 완성하면… 이야기의 끝이 기다립니다

### 🐴 조랑말과 경마
- **당근을 하루에 한 번은 꼭** 먹여야 합니다 — 굶기면 울고, 7일이면 죽습니다
- 애정(먹인 당근)이 쌓일수록 경마 승률이 오릅니다 (기본 10% + 당근 1개당 1%)
- 마구간 옆 팻말에서 참가비 20,000원으로 출전, 1등 상금 100,000원

### 🌅 살아있는 섬
- 해가 뜨고 지는 하루(10분), 아침마다 새로운 소식
- **오늘의 사건**: 태풍(물질 금지) · 황금향 · 물반 고기반 · 장날(상점 반값)
- 이장님·돌하르방·해녀 할망과 대화, 🎒 가방(갖고 있는 아이템 보기)
- 진행 상황은 자동 저장됩니다
