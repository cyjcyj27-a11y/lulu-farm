# 루루냥의 제주살이

고양이 루루가 제주도에서 귤 농사도 짓고 물질도 하며 살아가는 3D 게임입니다.
브라우저만 있으면 되고, 따로 설치할 것은 없습니다.

**▶ 바로 하기 : https://cyjcyj27-a11y.github.io/lulu-farm/**

## 지금 할 수 있는 일

### 🍊 감귤 농사

밭담으로 구획된 귤밭이 섬의 절반을 덮고 있습니다 (밭 19개, 나무 450여 그루).

1. 감귤나무 가까이서 **F** — 딴 귤이 상자에 한 알씩 쌓입니다 (36알이면 가득)
2. 상자 옆에서 **E** — 붙잡고 끌 수 있습니다
3. 마당 왼쪽 **택배사**에서 **F** — 트럭에 실려 육지로 가고 정산받습니다 (한 상자 14,400원)
4. 상점 앞 판매대에서 **당근**(1,000원)과 **해녀 산소통**(30,000원)을 팝니다

### 🤿 해녀 물질

마당에서 북쪽으로 쭉 걸어가면 바닷가에 **포구**가 있습니다.

1. 포구에서 **F** — 바다로 들어갑니다
2. 물속에서 **F**로 전복·소라·미역을 따서 망사리에 담습니다 (24개까지)
3. **Space**로 떠올라 숨을 쉽니다. **숨이 다하면 정신을 잃고, 망사리에 담은 것을 전부 잃습니다**
4. **E**로 뭍에 나오면 딴 것을 한꺼번에 팝니다 (미역 100 / 소라 1,000 / 전복 10,000원)

> 상점 옆 판매대에서 **해녀 산소통**(30,000원)을 사면 숨이 26초 → 60초로 늘어납니다.
> 물속은 뭍과 조작감이 다릅니다. 서서히 붙고, 손을 놓아도 한참 미끄러집니다.
> 숨이 줄면 화면 가장자리가 조여오고 몸이 무거워집니다.

### 🏚 헌집 고치기

마당 동쪽에 버려진 돌집이 있습니다.

1. 폐가 앞에서 **F** — 50,000원에 삽니다
2. **F**를 누를 때마다 한 단계씩 고칩니다 (벽 → 지붕 → 페인트, 각 15,000원)
3. 다 고치면 내 집! 창고가 생겨 귤 상자 정원이 36 → 48로 늘어납니다

## 조작

**컴퓨터**

| 키 | 하는 일 |
|---|---|
| 방향키 | 루루 이동 |
| A D | 시야 좌우로 돌리기 |
| W S | 올려보기 / 내려다보기 |
| Z X | 줌 |
| F | 귤 따기 · 상점 · 택배 · 물질 · 채집 |
| E | 상자 잡기 / 놓기 · 물질 끝내기 |
| Shift | 달리기 |
| Space | 점프 · 물속에서 떠오르기 |
| M | 배경음악 켜기 / 끄기 |

돌담은 점프해서 뛰어넘을 수 있습니다.

**폰**

- 왼쪽 화면을 끌면 루루가 걸어갑니다 (살짝 기울이면 천천히)
- 오른쪽 화면을 끌면 시야가 돌아갑니다
- 두 손가락으로 벌리고 오므리면 줌
- 오른쪽 아래 버튼: 🍊 따기·거래 / 📦 상자 / 💨 달리기 / ⤴ 점프
- 왼쪽 아래 🎵 배지를 누르면 배경음악이 꺼집니다

## 폴더 구성

```
index.html   게임으로 넘어가는 문
game/        게임 코드 (jeju3d.html, jeju3d.js, three.js)
assets/      루루 그림, 성산일출봉 그림, 배경음악
```

그림은 원본 PNG를 WebP로 눌러 담아 올립니다 (6.3MB → 2.3MB). 원본은 작업 폴더에 그대로 둡니다.
